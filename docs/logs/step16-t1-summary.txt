## Carrier evidence statement (T1 requirement)

- application/json: PROVEN - the engine's Coraza transaction receives the
  body (framing gate passes it, proxy.go reads it up to
  max_inspected_bytes) and populates ARGS/ARGS_NAMES via the URLENCODED
  fallback (audit evidence in (c)/(d)); the connector populates them via
  the JSON processor (image rule 200001).
- text/plain, application/octet-stream, unknown content type: the engine
  passes the body through the same 901340-forced URLENCODED fallback
  (same code path, PROVEN from source (a)); no engine audit entries exist
  for these carriers in the T6 runs because every such request passed
  (RelevantOnly audit). The connector never inspected these carriers in
  the default policy (920420 blocks in phase 1 before body processing).
  Post-fix per-carrier variable population is proven by the E13 test
  (XML) and the T2 re-run outcomes.
