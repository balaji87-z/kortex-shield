== CORRECTION (2026-11-19, later the same day): section 3 above is WRONG about the cause.
The runner always sends len(encoded bytes) as Content-Length and drops recorded CL headers
(kortex_eval/runner.py lines 75-93); the 653 recorded-CL mismatches never reach the wire.
Reproduced root cause: tools/stub_backend.py never read request bodies, so on HTTP/1.1
keep-alive the next request was parsed from the leftover body ('{"url":...}GET' -> 501 ->
953110/959100 outbound block). Fixed in tools/stub_backend.py (_drain_body); verified
200/200 live. See docs/baseline-config.md step-11 correction entry and
docs/logs/step11-t4-stub-drain.txt for the raw experiment.
